# NyayaFlow AI – Prototype
AI-assisted pre-hearing case readiness (Seva Innovation Challenge).

## Run
1. Install Node.js (LTS) – https://nodejs.org
2. `npm install`
3. Copy `.env.local.example` to `.env.local` and paste a Gemini key (optional; empty = demo mode)
4. `npm run dev` → open http://localhost:3000

Try it with the PDFs in `sample-docs/`.

## Features
Create case · Upload PDFs · AI obligation extraction · Evidence check · Readiness score · Manual status override · Timeline · Print/export
